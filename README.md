# 🛒 E-Commerce Data Analysis Dashboard

##  Project Overview

This project is an interactive **E-Commerce Data Analysis Dashboard** built using **Microsoft Power BI**. The main goal of the project is to understand how an e-commerce business is performing by analyzing orders, sales, delivery performance, customer ratings, refunds, categories, and store-wise performance.

I created this project to practice real-world data analysis and turn raw business data into simple, meaningful insights that can help with better decision-making.

##  Objectives

* Analyze overall sales and order performance
* Track total orders and revenue
* Understand delivery delays and delivery performance
* Analyze customer ratings
* Identify high-performing stores and categories
* Monitor refunds and order status
* Compare performance across different stores
* Create an interactive dashboard for business users

##  Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Excel/CSV** – Data source
* **Data Analysis** – Trend and performance analysis

##  Dashboard Features

### Main Dashboard

The main dashboard provides an overall view of the business, including:

* Total Orders
* Total Sales/Revenue
* Customer Ratings
* Delivery Performance
* Refunds
* Order Status
* Category Performance
* Store Performance

### Store-Level Analysis

The dashboard also allows users to explore individual stores and understand their performance in more detail.

Users can filter the dashboard and compare:

* Store-wise orders
* Store-wise sales
* Customer ratings
* Delivery delays
* Refunds
* Product/category performance

##  Key Analysis

Some of the questions explored in this project include:

* How many orders were placed?
* Which stores are performing the best?
* Which categories generate the most sales?
* How many orders were delivered late?
* What is the average customer rating?
* How many orders were refunded?
* Which stores have better delivery performance?
* What factors are affecting customer satisfaction?
